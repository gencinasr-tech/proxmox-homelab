# Duplicati - Backups Cifrados

Sistema de backups cifrados a la nube con Duplicati.

## 📋 Información

- **Servicio:** Duplicati
- **Función:** Backups automáticos cifrados
- **Destino:** Google Drive, OneDrive, S3, etc.
- **Cifrado:** AES-256

## 🎯 Características

- 🔐 Cifrado end-to-end
- ☁️ Múltiples destinos cloud
- 📅 Programación automática
- 🔄 Backups incrementales
- 📊 Interfaz web intuitiva
