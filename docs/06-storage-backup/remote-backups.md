# Backups Remotos

Estrategia de backups remotos cifrados en la nube.

## 📋 Información

- **Destino:** Google Drive, OneDrive, S3
- **Cifrado:** AES-256
- **Frecuencia:** Diaria
- **Herramienta:** Duplicati, rclone

## 🎯 Regla 3-2-1

- **3** copias de datos
- **2** tipos de medios diferentes
- **1** copia offsite (remota)
