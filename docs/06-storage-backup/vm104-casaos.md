# VM104 - CasaOS

Sistema de almacenamiento y gestión de archivos con CasaOS.

## 📋 Información de la VM

- **ID:** VM104
- **Hostname:** casaos
- **IP LAN:** 192.168.1.104
- **OS:** CasaOS (basado en Debian)
- **Recursos:** 2 CPU, 4GB RAM, 32GB disco + almacenamiento adicional

## 🎯 Propósito

CasaOS proporciona:
- 📁 Gestión de archivos centralizada
- 🐳 Interfaz para Docker simplificada
- 📦 App store integrado
- 💾 Gestión de almacenamiento
- 🖥️ Dashboard intuitivo
