# CT106 - Vaultwarden

Gestor de contraseñas auto-hospedado compatible con Bitwarden.

## 📋 Información del Contenedor

- **ID:** CT106
- **Hostname:** vaultwarden
- **IP Privada:** 10.10.10.60
- **OS:** Debian 12
- **Recursos:** 1 CPU, 1GB RAM, 8GB disco

## 🎯 Propósito

Vaultwarden proporciona:
- 🔐 Gestión segura de contraseñas
- 👥 Compartir contraseñas en familia/equipo
- 📱 Apps para todos los dispositivos
- 🔒 Cifrado end-to-end
- 💾 Backups automáticos

## 🔒 Seguridad

- **Criticidad:** CRÍTICA
- **Acceso:** Solo vía proxy con SSL
- **2FA:** Obligatorio
- **Backups:** Diarios cifrados

## 📚 Documentación Detallada

Para instrucciones completas de instalación y configuración, consulta la documentación principal del proyecto.

## 🔗 Acceso

- **Interno:** http://10.10.10.60:80
- **Externo:** https://vault.tu-dominio.com (vía Nginx Proxy Manager)
