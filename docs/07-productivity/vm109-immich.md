# VM109 - Immich

Plataforma de gestión de fotos y videos auto-hospedada.

## 📋 Información de la VM

- **ID:** VM109
- **Hostname:** immich
- **IP Privada:** 10.0.0.109
- **OS:** Ubuntu Server 22.04
- **Recursos:** 4 CPU, 8GB RAM, 64GB disco + almacenamiento

## 🎯 Propósito

Immich proporciona:
- 📸 Backup automático de fotos desde móvil
- 🎥 Gestión de videos
- 🔍 Búsqueda por contenido (ML)
- 👥 Compartir álbumes
- 🗺️ Visualización en mapa
- 📱 Apps móviles nativas
