# CT115 - qBittorrent (Descargas)

Cliente de torrents con interfaz web.

## 📋 Información del Contenedor

- **ID:** CT115
- **Hostname:** downloads
- **IP Privada:** 10.10.10.83
- **OS:** Debian 12
- **Recursos:** 2 CPU, 2GB RAM, 12GB disco + almacenamiento de descargas

## 🎯 Propósito

qBittorrent proporciona:
- 📥 Cliente torrent completo
- 🌐 Interfaz web
- 🔍 Motor de búsqueda integrado
- 📊 Gestión de ancho de banda
- 🔒 Soporte VPN
- 📱 Apps móviles
