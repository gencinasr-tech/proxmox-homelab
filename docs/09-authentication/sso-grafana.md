# SSO con Grafana

Configuración de Single Sign-On para Grafana usando Keycloak.

## 🎯 Objetivo

Integrar Grafana con Keycloak para:
- 🔐 Autenticación centralizada
- 👥 Gestión de usuarios desde Keycloak
- 🔑 Login único (SSO)
- 📊 Mapeo de roles automático
