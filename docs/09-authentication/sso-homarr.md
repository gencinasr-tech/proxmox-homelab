# SSO con Homarr

Configuración de Single Sign-On para Homarr usando Keycloak.

## 🎯 Objetivo

Integrar Homarr con Keycloak para:
- 🔐 Autenticación centralizada
- 👥 Gestión de usuarios desde Keycloak
- 🔑 Login único (SSO)
- 🏠 Acceso seguro al dashboard
