# SSO con Immich

Configuración de Single Sign-On para Immich usando Keycloak.

## 🎯 Objetivo

Integrar Immich con Keycloak para:
- 🔐 Autenticación centralizada
- 👥 Gestión de usuarios desde Keycloak
- 🔑 Login único (SSO)
- 📸 Acceso seguro a fotos
