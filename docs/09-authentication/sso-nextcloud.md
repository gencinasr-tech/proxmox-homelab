# SSO con Nextcloud

Configuración de Single Sign-On para Nextcloud usando Keycloak.

## 🎯 Objetivo

Integrar Nextcloud con Keycloak para:
- 🔐 Autenticación centralizada
- 👥 Gestión de usuarios desde Keycloak
- 🔑 Login único (SSO)
- ☁️ Acceso seguro a archivos
